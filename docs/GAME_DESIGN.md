# AXEHOLD — Game Design Snapshot

## Pillars
1. **One-thumb clarity** — игрок понимает управление за несколько секунд.
2. **Meaningful preparation** — дневная добыча напрямую меняет шанс пережить ночь.
3. **Short-term dopamine + long-term goals** — ресурс/убийство → перк → постройка → босс → открытие биома.
4. **Fair monetization** — rewarded-реклама ускоряет, но не блокирует прохождение.

## Core loop
Добыть → выгрузить → решить, что строить → пережить волну → выбрать перк → повторить → победить босса → усилить мету.

## Session target
Одна экспедиция: примерно 4–8 минут после балансировки.

## Monetization hooks
- одно rewarded-воскрешение на забег;
- ×2 монеты после результата;
- supply drop между волнами;
- косметические покупки можно добавить отдельно.
