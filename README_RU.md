# AXEHOLD: Last Hearth

Играбельный production-oriented прототип **v1.20.0-alpha.1** для **Godot 4.7.2 stable**.

## Что уже реализовано
- Главное меню: лагерь, карта, кузница, задания, коллекция, настройки.
- 3 биома с разной сложностью и наградами.
- Короткий цикл: день → добыча/стройка → ночь → волны → босс.
- Дерево, камень, руда, рюкзак и склад.
- Постройки: забор, кузница, турель, святилище.
- Вращающиеся топоры, автоатака, XP и выбор перков.
- Три типа обычных врагов и босс с телеграфируемой зональной атакой.
- Постоянная мета-прокачка героя.
- Косметические облики.
- Миссии и трофеи.
- JSON-сохранение в `user://axehold_save.json`.
- Заглушки сервисов Rewarded Ads и Analytics для дальнейшей замены SDK.

## Запуск
1. Установите Godot 4.7.2 stable.
2. Откройте папку проекта через **Import** и выберите `project.godot`.
3. Нажмите F6/F5. Основная сцена уже назначена.

## Управление
- Компьютер: клик / удержание мыши.
- Телефон: касание / перетаскивание.
- Герой идёт к выбранной точке. Атака и добыча работают автоматически.

## Важно
Это исходный vertical slice, а не подписанный APK/IPA. Перед коммерческим релизом нужны: настоящие art/audio ассеты, SDK рекламы, IAP при необходимости, crash/analytics SDK, privacy/consent flow, локализация, device QA и store signing.
