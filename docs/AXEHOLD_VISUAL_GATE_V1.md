# AXEHOLD Visual Gate v1

Статус: экспериментальная визуальная ветка поверх стабильного gameplay baseline.

## Цель

Доказать, что текущий AXEHOLD можно довести в Godot до вида, который воспринимается как законченная коммерческая мобильная игра, не переписывая игровой цикл и не меняя баланс.

## Жёсткая граница

Visual Gate не меняет:
- правила экспедиции;
- экономику ресурсов;
- Threat I–V;
- события, постройки, NPC, боссов и мета-прогрессию;
- автоатаку и автодобычу;
- выбранное оружие;
- длительность дня/ночи.

Visual Gate меняет только presentation layer:
- герой и его анимация;
- свет и цвет;
- окружение;
- VFX;
- читаемость интерактивных объектов;
- камера и визуальная обратная связь;
- HUD только в части визуальной полировки.

Стабильная экспедиция запускается как раньше. Visual Gate включается только через отдельную кнопку визуального теста.

## Визуальная цель

Один кусок реальной экспедиции должен выглядеть так, чтобы его можно было показать как скриншот продукта:
- цельный герой без изменения роста и масштаба;
- естественная походка во всех направлениях;
- единая hand-painted / clean fantasy стилистика;
- тёплые акценты против холодной чащи;
- мягкая глубина кадра без перегруза декором;
- свет, туман, частицы и удары работают как одна система;
- оружие визуально принадлежит герою и не выглядит наклеенным;
- ночь заметно меняет атмосферу, но не ухудшает читаемость;
- крупный объект всегда имеет функцию.

## Этапы

### VG-1 — Atmosphere foundation
- отдельный VisualGateFX, который существует только в preview-режиме;
- мягкая цветокоррекция;
- виньетка;
- лёгкий film grain;
- динамический тёплый свет центральной зоны;
- лёгкий fill-light героя;
- плавный переход день/ночь.

### VG-2 — Hero production pass
- единый baseline стоп;
- одинаковый рост во front/side/back;
- одинаковый визуальный центр;
- walk cycle без скольжения;
- idle, hit, defeat как минимальный набор;
- без составного ragdoll.

### VG-3 — Environment pass
- hand-painted земля и дороги вместо технических примитивов;
- ограниченный декор;
- деревья/камни/руда читаются как интерактивные;
- мягкие тени и контакт с землёй;
- 1 законченная поляна как quality target.

### VG-4 — Combat feel
- slash/trail для каждого семейства оружия;
- impact flash, sparks, hit-stop/shake в безопасных пределах;
- смерть врага без визуального мусора.

### VG-5 — Release HUD pass
- убрать техническое ощущение;
- сохранить минимум постоянной информации;
- проверить safe-area на iPhone.

## Приёмка Visual Gate

Visual Gate принимается, если:
1. по 10–15 секундам видео игра не выглядит как прототип;
2. герой не меняет размер и не скользит;
3. земля, ресурсы, враг и герой выглядят частью одной сцены;
4. день и ночь отличаются атмосферой, а не просто затемнением;
5. стабильная версия AXEHOLD не изменила геймплей;
6. визуальный режим держит стабильный FPS на целевом iPhone.

Если VG-1—VG-5 проходят, Godot остаётся основным движком. Если главным ограничением остаётся именно персонаж, следующий тест — 2.5D character pipeline внутри Godot.
