# AXEHOLD Master Vision

## Product
AXEHOLD: Last Hearth is a portrait, one-thumb, mobile-first hybrid-casual survival builder with light roguelite progression.

**Core promise:** Cut by day. Hold by night.

The player must feel a satisfying chain:
1. Move naturally with one thumb.
2. Auto-harvest resources with orbiting weapons.
3. Watch the backpack fill locally above the hero.
4. Decide whether to push farther for valuable resources or return before night.
5. Deposit resources into the Last Hearth.
6. Build visible, meaningful defenses/upgrades.
7. Survive the night using both the hero and the camp.
8. Repeat for three nights, defeat a biome guardian, return to a persistent living camp.

## Non-negotiable design pillars
- Gathering must be satisfying.
- Building must be meaningful.
- Night must test the player's preparation.
- The game must be readable on a phone without constant explanatory text.
- Core movement and combat must remain one-thumb accessible.
- Forced advertising must never be required for the core loop.
- The world should tell the story through growth, light, ruins, relics and progression rather than long dialogue.

## Final visual target
Modern 16-bit / HD pixel survival:
- crisp readable silhouettes;
- authored sprites replacing prototype procedural shapes over time;
- smooth camera and movement;
- modern particles, glow and hit feedback;
- strong warm Last Hearth versus cool/dark threatened world;
- minimal HUD;
- readable role-based enemies;
- no emoji-dependent production UI.

## World structure
The Last Hearth sits in the center of a multi-screen expedition map.
- Near zone: safe/common wood and basic stone.
- Mid zone: richer stone, more travel risk.
- Far zone: ore, events, elite threats and high-value decisions.
- Camera follows the hero.
- A return cue appears when the bag is nearly full, night is close, or night has begun.

## Controls
Default mobile control is a floating dynamic joystick:
- touch anywhere in the playable area;
- joystick appears at the touch point;
- the base drifts softly with large thumb movement;
- release hides it;
- attacks remain automatic.
Alternative fixed/tap modes may exist later as accessibility options.

## Run structure
Target expedition length: roughly 6–9 minutes.
- Day 1 -> Night 1 -> choice
- Day 2 -> Night 2 -> choice
- Day 3 -> Night 3 + Guardian
- Return home

## Buildings
- Palisade: protects the Hearth and slows nearby attackers.
- Forge: improves hero weapon power/reach.
- Tower: automated ranged support.
- Shrine: hero/Hearth recovery and sustain.

Players should not routinely afford everything immediately; building order must be a decision.

## Soft-launch scope
- 3 biomes
- 4 weapon identities
- 4 expedition buildings
- 5 core enemy roles + elite variants
- 3 guardians
- persistent camp
- meta upgrades
- boss relics / biome mastery
- rewarded ads only at launch

## Product test
A build is not successful because it compiles. It must prove that a new player can:
- move immediately;
- understand harvest -> bag -> Hearth -> build;
- feel the preparation/night relationship;
- finish or fail a run and want to start another.

Every new system must make gathering more satisfying, building more meaningful, or night more exciting. If it does none of these, it does not belong in AXEHOLD yet.
