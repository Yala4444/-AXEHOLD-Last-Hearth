# AXEHOLD V1.23 — Concept I Vertical Slice

This slice is the first playable proof of the selected **Clean Cel-Shaded Action Adventure** direction. It is intentionally isolated from the production expedition so the two experiences can be compared safely.

## Playable loop

1. Move with the floating touch joystick, mouse drag, arrows, or WASD-equivalent UI actions.
2. Approach the old tree; the orbiting axes harvest it and the tree visibly changes across four damage states.
3. Carry the wood to the Hearth to construct the watchtower.
4. Survive the day-to-night transition against the Thorn Hound and Root Husk.
5. Protect the Hearth while the completed tower fires supporting shots.

## Art contract

- bright natural daylight and a readable warm/cool palette;
- painterly cel-shaded forms with strong silhouettes;
- authored environment art rather than a flat procedural floor;
- true changing walk/run poses for the hero and enemies;
- restrained dark-fantasy accents without making the whole game oppressive;
- mobile-first readability at 390 × 844.

The home screen entry point is **ПОПРОБОВАТЬ НОВЫЙ ВИЗУАЛ · CONCEPT I**. Returning from the slice never alters progression or save data.
